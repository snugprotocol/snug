# Lessons — distilled 2026-08-15

Forward-looking rules only, grouped by theme. **The agent reads this when planning (Gate 2).** The full narratives live in git history of this file (pre-distillation) per ADR-0027. Entry dates are preserved for archaeology. Add new rules to the matching section at Gate 6; when a section outgrows a screen, re-distill.

## Tests that can fail

- (2026-08-04) A test never seen to fail tests nothing: mutation-check every guard by reverting the fix and watching red. Be suspicious of first-run passes, assertions behind optional calls (`backend.list?.()`), and subjects only reachable in modes the test never enters.
- (2026-08-04) Assert the requirement's OUTCOME in one sentence, never a correlating proxy — if the broken and fixed artifacts both pass, the test measured nothing. Earned twice: hub "reachability" passed with the forked-app bug restored; icon "centred" passed on a 61% logo when the ask was full-bleed.
- (2026-08-08) Mutate the rule AND its call site: deleting the Settings revoke button's call left every test green because the rule was only ever invoked directly. "Logic is correct" and "logic runs" are separate claims.
- (2026-08-13) A refusal's test input must pass every SIBLING refusal and fail only the one under test — `runLanPairing`'s approved-status check survived deletion because hostless fixtures never reached it. When a mutation stays green, suspect the fixture before the mutation.
- (2026-08-08) When a test seam short-circuits production wiring, at least one test runs with the seam OFF — every suite injected `__setDeclarationManifestsForTests`, so a misspelled `import.meta.glob` kept 477 tests green with the feature inert for real users. Mutation-check the wiring, not just the logic.
- (2026-08-13) A fence that restates its data cannot test it: drive the value through the code that CONSUMES it, with fixtures hostile to the mechanism — `hue.pairing.secretPath` was compared to a retyped copy of itself (green against a path no real bridge answers); URL-safe hex keys made four C1 scrub tests decorative.
- (2026-08-11) Test matrices must repeat an operation KIND (write/write exposes what write/read hides — `sqlite3_changes()` deltas); a guard comparing two values from the SAME function verifies agreement, not correctness; neutralize the delimiter PRIMITIVE, not one spelling — the attacker picks the spelling.
- (2026-08-13) Verify a timing fix by measuring failure RATE before/after, and check the ENCLOSING budget — a 10s `vi.waitFor` inside the 5s default test timeout is dead code. Intermittent + every-added-log-makes-it-pass = scheduler/ordering bug, not slowness.
- (2026-08-13) A mutation that stays green is evidence, not a dead end — ask what its survival proves (a microtask drain can't advance real timers → the chain awaits real async). Once an environmental failure reproduces deterministically, re-run the whole file under that condition.
- (2026-08-10) When a rebuild deletes a surface, classify every deleted test: MIGRATED (cite the new assertion), OBSOLETE (prove the code is gone), or LOST — the v2 wizard rebuild orphaned 14 shipped behaviors including `isConnectionRepairableNetError`'s allowlist. A net test-count drop is a prompt to audit, never an explanation.
- (2026-08-04) Test doubles wrapping one-shot resources (streams, iterators, FormData) must be factories — one mocked SSE `Response` served to two turns yields a silent empty second turn.
- (2026-08-05) Test at the altitude where the DECISION is made, not where the effect lands — AC12 asserted `cache_control` at the adapter while callers cached the wrong turns in both directions (ADR-0012). Per-request switches belong on the call; the test belongs on the caller.

## Trusting a green run

- (2026-08-13) A lane's green is a sample of a different distribution; the integrating claim is the forced ROOT run (`turbo run test --force`, showing `Cached: 0 cached`) — repeated, because the catches came on the fourth and tenth runs.
- (2026-08-10) The turbo cache replays stale greens, and dependents resolve workspace packages via `dist/` — after any mutation, re-run with `--force`; mutate `src/` and rebuild (or `dist/` deliberately, then restore) or you are proving nothing.
- (2026-08-11) Run turbo from the REPO ROOT — inside a package dir it silently scopes to that package's graph (a 19-task run became 4). Every package's `test` script is tsc-gated now; keep that uniform, and when enabling a type gate read the whole backlog — 2 of 40 hidden errors were assertions voided behind `as` casts.
- (2026-08-06) A suite is proven only when shown to RUN: watch for "no tests"/"failed to load", and verify loadability in isolation on a cold `.vite` cache — warm sibling resolvers let a phantom `zod` import pass every batch run. Every runtime import needs a dep in that package's own package.json; fix by removing the import, not adding the dep.
- (2026-08-10) An empty grep on a file you expect hits in needs a second tool (`grep -a`, ripgrep, Python) — one NUL byte made grep silently print nothing and "confirm" a deletion. No output is a possible tool failure, never evidence of absence.

## Real browsers & rendered surfaces

- (2026-08-14) Geometry defects ("one char per line", "overlaps", "cut off") close only by measuring the rendered box in a real browser — `getBoundingClientRect()` ratios in Playwright; jsdom rects are 0×0 and stylesheet-text assertions pass on broken layouts. When a repro fails, suspect the ELEMENT (`.llm-summary`, not `.llm-block`) before the mechanism.
- (2026-08-06) A sandbox/CSP flag disables whole DOM behaviors, not just channels — C2's `allow-scripts` blocks form submission before `submit` dispatches, so `<form onSubmit>` apps were jsdom-green and browser-dead. Enumerate what a flag disables; encode each item as a validator lint plus one real-browser probe per flow.
- (2026-07-31) Assert the enforcement SIGNAL, never the API return value — Chromium's `sendBeacon` returns true even when `connect-src` blocks the send; use `securitypolicyviolation` events and absence of network effect.
- (2026-08-07) Never let CSS generated content carry a fact a checker must verify — a counter on an unnumbered h2 shifted every section number, invisible to source greps AND PDF text extraction. Numbers go in literal text; budget one visual pass over rendered pages.
- (2026-08-06) Probe browser capabilities on a real origin, never `about:blank` (not a secure context — `navigator.gpu` absent there); demand the working handle (adapter/device, not the API object), and vary channel × headedness before believing an absence.
- (2026-08-03) OPFS persistence-across-reload claims need `launchPersistentContext` with a disk-backed profile, a bytes-on-disk wait plus settle beat before navigating — ephemeral-context OPFS dies across hard navigations, and `page.route` stalls vite module loading.

## Sandbox, credentials & cross-package seams (C1/C2)

- (2026-08-12) A guard expressed as a request OPTION (`redirect`, `signal`, TLS flags) is voided by a new transport by default — tauri's shim never reads `init.redirect`, silently disabling `NET_REDIRECT_BLOCKED` on desktop and forwarding injected credentials through redirects. Read the transport's option-parsing source; test that the option ARRIVES. A seam guarantees shape, never semantics.
- (2026-08-13) When a lane spans two packages, assert the seam's IDENTITY from the integrating side (`platform.lanFetch toBe lanFetch`) and mutate the seam — deleting the wiring left both packages' suites green, twice, by construction: one owns the implementation, the other owns a stub, nothing owns the wire.
- (2026-08-13) A new capability/placement seat rides EVERY surface the existing seat rides — schema, lint, admission, executor, scrub, REVIEW COPY, migration — or the task file says why not. `queryTemplate` shipped past the wizard's review screen: a seat that skips consent is admitted for free (ADR-0017's price).
- (2026-08-12) A guard that both REFUSES and REWRITES drives both halves from one resolution — Guard 2b's accept-list was widened while `applyRegistryValues` still rewrote the user's chosen option back to the default. Assert the PERSISTED shape, never "not refused"; and a plan's "no changes to X needed" is a claim to trace, not a scope note.
- (2026-08-15) A change GATE and its disclosure SURFACE must share one comparison semantics, derived from what the value MEANS — the scope-drift digest compared ordered arrays while the diff screen rendered set membership, so a reordered-but-equal list staged an approval whose every rendered line read "unchanged", and approving the invisible diff destroyed a working connection's tokens. Ask "is this value a set or a sequence?" once, and derive both seats from the answer (RFC 6749 scopes are a set).
- (2026-08-15) A destructive act paired with a state transition runs BEFORE the transition when the pre-state is the recoverable one — token invalidation after `reapproveConnection` meant a mid-write throw stranded a promoted row whose drift migration would answer 'none' forever; inverted, a throw leaves the old requirement plus the staged diff, and the next wizard open heals it. Pin the ordering with a call-order spy, not a comment.
- (2026-08-11) Where an approval gate's whole signal is one number, REFUSE the operation classes the number cannot describe — `sqlite3_changes()` is 0 for all DDL, so `DROP TABLE` previewed as "0 rows"; it is also sticky, so attach it by operation kind. And absence of local state is never consent: trust comes from a provenance-bearing caller (`trustedOrigin`), default untrusted.
- (2026-08-06) When a security guard blocks your test fixture (SSRF guard vs a 127.0.0.1 stub), the guard is working — never loosen it or add a bypass; make the fixture look like what the guard should allow (`stub.snug.test` via host-resolver-rules), scoped so the allowance cannot leak. `Failed to fetch` is usually CORS, not TLS.
- (2026-08-14) A "does X reference Y" check over template data must match the reference TOKEN in the value grammar (`{{...field...}}`), never a substring over serialized structure — header NAME `hue-application-key` satisfied a substring check for field `application_key` (ADR-0025 verify probe).
- (2026-07-31) Port the hardening, not the bugs: carry the DB invariants + host-freeze from the hardened source system and the PKCE/refresh/scrubbing from the original; strictness is never a flag (C1).
- (2026-07-31) One contract must never live in two artifacts by convention — inject from one source or byte-compare in CI; for CI-only artifacts no local suite executes (`gate/run-gate.mjs`), DERIVE the value by parsing the source of truth and pin the derivation with a fast local test. Keep such drivers fail-loud on unknown ids.
- (2026-08-03) Pin every shared literal (header names, cookie names, routes, error codes) verbatim in both task files before fan-out, or in one imported constants module — two agents invented `x-snug-csrf` vs `x-csrf-token` and integrated dead-on-arrival.

## Diagnosis & stream forensics

- (2026-08-14) One symptom can have several independent producers: when a symptom rides shared state, grep the FLAG for every writer before claiming a fix — the pending-ticker had three producers and was "fixed" wrongly twice. State which producers you closed and which you did not.
- (2026-08-12) Diagnose "nothing happens" from the user's first visible surface inward, never from the component nearest the feature — the Coinbase CTA died at `openConnectionWizardForApp`'s zero-row guard, a layer above both diagnoses. An error state is not surfaced until something RENDERS it; grep for the subscriber.
- (2026-08-12) A causal chain or ranked hypothesis is fiction until the suspect input runs through the real code — a 3-line probe of `balancedObjects` refuted the #1 theory before any repro, and recon killed a "replayed conversation" mechanism a fix would have been built on. Pin every refutation as a characterization test so the dead theory cannot be re-inherited.
- (2026-08-05) A state variable's meaning is relative to its reader: when repointing a surface at existing state (`steps` → live status line), re-ask what the state means at start/mid/end/error/abort, and prefer the signal whose name matches the new question (`busy`). One test must drive real state through a full turn.
- (2026-08-05) Replacing a bound means re-deriving it: enumerate every retained field and every event that can GROW an existing record — the byte budget's size function omitted fields (off by 166,000×) and its keep-the-newest escape hatch exempted the one entry that kept growing. One adversarial test per growth path.
- (2026-08-12) When a stream looks truncated but `stop_reason` says finished, compare `usage.output_tokens` to delivered chars and look for tail-references-to-missing-head — a big gap convicts DELIVERY, and no parser change may ever make corrupt bytes "parse".
- (2026-08-12) To clear or convict a framing layer, replay a real captured stream through the real code split at EVERY byte boundary and assert byte-identical assembly; keep the suite as a tripwire — if it ever reds, your layer has ACQUIRED the bug (P0, not flake).

## Agents, reviews & process memory

- (2026-08-12) Any agent that WRITES gets `isolation: "worktree"` — file-disjoint lanes still share the git index (raced commits, a stash displacing in-flight work), and mutating reviewers in a shared tree measure each other's breakage. Concurrency without isolation is only safe for read-only reviewers; otherwise serialize commits through the orchestrator.
- (2026-08-13) Re-derive consequential agent claims from primary sources before acting on or repeating them — a platform-blocking verdict was confirmed link-by-link in the pinned crates first; a reported "production typo" was another reviewer's live mutation. The more concrete the claim, the more tempting to skip exactly the check that would expose it.
- (2026-08-15) A comment's claim about ANOTHER surface is a pointer to verify, never evidence — ADR-0028's whole "consent is visible" justification rested on a protocol comment saying "`scopes` is what the review renders" while no renderer existed (the fresh-context plan review's blocker). Before citing "X renders/enforces/strips Y", grep for the consumer; a doc-comment can describe an intention nobody built.
- (2026-08-08) Pair every finder with an independent refuter that defaults-to-refuted and must produce a runnable probe, not an argument — 4 of 10 review findings died, each a would-be "fix" to correct code.
- (2026-07-31) Every High/Medium merge gets a fresh-context adversarial review that RUNS probes against the constraint surfaces — pre-merge reviews caught a C1 credential leak via `responseSchema` and a meta-CSP bypass that the authors' green suites missed.
- (2026-08-08) Design review and implementation review find disjoint defect classes — five design reviews bought zero protection against a call-site default mismatch and a missing test. Budget both for High-tier surfaces; "the design was reviewed hard" is zero evidence about the code.
- (2026-08-10) Multi-phase work ends with a WHOLE-SURFACE review tracing one datum end to end, asking at every handoff what the receiver trusts that the sender never guaranteed — two lints disagreeing about "declared" fields was invisible to eleven green per-phase reviews.
- (2026-08-12) A consumer's first act is verifying the producer's work EXISTS in the shared substrate (commits present, symbols grep-able), never trusting the handed-in summary; an empty fan-out result is a tool-failure hypothesis before a no-findings conclusion. Budget one integration probe across independently-green components — the first real boot is a test.
- (2026-08-15) A dependent package's green suite vouches for the producer's last BUILD, not its source: apps resolve `@snugprotocol/*` through `dist/` (package.json `main`), so after editing a package's src, rebuild it BEFORE trusting any dependent's local vitest run — playground ran 103/103 "green" against a two-day-stale auth build while its own fixtures contradicted the new registry. Root `turbo run test --force` rebuilds via the task graph; bare `vitest` in an app does not.
- (2026-08-08) Repeating a journaled mistake means the journal entry is the defect: rewrite it as a procedure change that makes the error unreachable ("commit before any mutation cycle"), never as a caution to remember. "Be careful about X" is not a fix.
- (2026-07-31) Verify any public-facing name (package, command, protocol message) against GitHub/npm/web in the session it is proposed — twenty "obviously free" candidates were all taken.
- (2026-08-07) A document derived from a spec is checked by diffing SETS and MODALITY, not token presence — `MALFORMED` "appeared" while the claim around it overclaimed the spec, and internal C1/C2 doctrine was silently promoted to protocol requirement. Grep the published source for each MUST/never/always before shipping it.

## Storage, config & mechanical edits

- (2026-08-03) Never `INSERT OR REPLACE`/upsert into a table you did not define without verifying the uniqueness constraint the conflict clause needs (`sqlite_sequence` has none; UPDATE-then-INSERT-if-zero is safe) — and restoration tests must exercise state that DIVERGES from what the system would re-derive (deleted-max rows), never the coincidentally-equal state.
- (2026-08-03) Durable browser-storage writes go to a NEW fixed-name file (A/B slots + pointer); reads are direct fixed-name lookups with magic checks and brief retries — OPFS teardown truncates in-place writes, and sql.js accepts zero bytes as a fresh DB, so an empty/magic-less read of a file that should exist is CORRUPT (quarantine), never "fresh".
- (2026-08-02) Config readers treat `''` as unset (`||` or trim-check) for any env var with a fallback — `SNUG_MODEL=` present-but-empty defeats `??`; env templates comment optional vars out rather than leaving them empty.
- (2026-08-14) A scripted extract-helper replacement must exclude (or run before inserting) the helper's own definition — the replace rewrote the helper's body into self-recursion. A sudden wide failure wave after a "safe" mechanical edit is the suite catching exactly this.
- (2026-08-14) An anchored Edit that consumes a heading must re-emit it verbatim, and append-only files get a headings-only grep afterward — a spec-changelog insert silently orphaned the prior entry's body under the new heading.
