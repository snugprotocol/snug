# Lessons

**A pasted token is a request target, so it gets the ceiling treatment.** The setup
token base64-encodes a URL. Trusting it would be a second host channel around the
frozen ceiling; checking it against registry-pinned hosts keeps the paste UX without
the paste risk.

**One host, or symbolic addressing dies.** A two-host ceiling (prod + beta bridge)
looked harmless and would have broken every `snug-connection://` request — resolution
demands ONE meaning — and aimed the test probe at the wrong bridge. The fresh-context
plan review caught it before a line shipped.

**Check the base path at claim time, not sync time.** The access URL's `/simplefin`
prefix is an assumption; refusing a divergent path when the claim runs converts a
silent future sync failure into a loud, explained, immediate one.

**Plant the demo's insights.** Random sample data shows charts; AUTHORED sample data
(two streaming overlaps, a dead trial, one price creep) shows the product. The
deterministic radar finding real flags in fake data is what makes the demo honest.

**Verification beats confirmation.** The feed itself proves a cancellation — the next
charge simply never arrives. No integration, no scraping: the data the app already
holds is the strongest evidence available.
