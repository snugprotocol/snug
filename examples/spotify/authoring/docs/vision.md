# Vision

Rewind is a listening portrait for a person's own Spotify account. Spotify shows you
music; Rewind shows you *yourself*: which artists own your rotation right now, how
concentrated or adventurous your listening is, how that changes visit over visit, and —
once a week if you like — a short magazine-style write-up of what it all says, written
by the agent from your real numbers.

It deliberately complements rather than clones. There is no browsing, no search, no
library. The one playback surface exists so you can see and steer what's playing from
inside the hub — with every control passing through the hub's confirm — not to replace
the Spotify app.

The part Spotify cannot offer at all: memory. Spotify's API only answers about the
present; Rewind journals a compact snapshot of every visit into a database the user
owns, so the trends page gets truer the longer the app lives.
