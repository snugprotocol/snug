# vision — Standup

GitHub shows everything; Standup shows what needs YOU. It is the two-minute
morning glance before the day starts: the review requests, assignments, and
mentions that are actually waiting on you, your own recent rhythm, and — on
request — an agent briefing that ranks the queue and suggests one concrete next
step per item.

**Complement, never clone.** No repo browser, no code view, no notifications
firehose. Acting on an item goes back to github.com (copied URL) or to the
provider chat lane (which confirms writes). Standup itself only ever reads.

**Truth stays on the wire.** Every number on screen comes from api.github.com
through the governed seam. The agent's only surface is the briefing, and an
off-schema reply is refused — the raw queue always stands.
