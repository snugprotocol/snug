# Lessons

**Let the model narrate, never adjudicate.** The agent's reply can colour a leg but
cannot move the hero, mint loot or open the sun door — those come from the scene
graph, and the deltas it may propose are clamped with a hard floor of one heart. The
worst possible reply is a bland leg, never a broken world: kid-safety lives in the
referee's arithmetic, not in the prompt.

**Off-schema is a designed state, not an error.** The demo brain's canned answer is
off-schema on purpose, so the local-guide fallback IS the demo's default path — and
the e2e journey drives it, asserting the visible note. A graceful-degradation branch
that the happy path exercises every run can never rot unnoticed.

**Split state by its shape.** Scalars (scene, hearts, gold) ride host KV, where
`usePersistedState` merges stored objects with defaults so new fields never arrive
undefined; collections (pack, journal) are real SQL tables. The collections are the
part worth exporting; the scalars are the part worth merging on upgrade.

**A strict referee absorbs protocol churn.** The authored app code has not changed
since the day it was born (2026-08-06): every later commit touched only the embedded
hook block — byte-synced as the net lane arrived — or added adjacent metadata
(`runtime-contract.json` on 2026-08-11 for ADR-0018, `starter.json` on 2026-08-21 for
ADR-0045). Keeping the app's claims small and local is what let three protocol
evolutions land without one app edit.
