  door are cheap — the map has room beyond seven scenes.
- A full-journal view: the in-app journal shows only the six most recent entries,
  though every leg is written — a "read my whole tale" screen (or an agent retelling
  drawn from the table) would use the data the app already keeps.
- An epilogue on the win screen assembled from the journal, instead of only the final
  leg's narration and the pack summary.

  state — an optional mode where an exhausted hero must rest before climbing would
  add stakes without touching the kid-safe default.
