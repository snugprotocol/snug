# Vision

Flying Pig Feed! is the shelf's origin story. Before Snug existed, an eleven-year-old
built a flying-pig game inside the founder's "Native Apps" feature — an app made by
asking, by someone who had never seen a compiler. This starter carries that proof onto
the shelf: the protocol's first constituency was a kid who wanted a game.

It is also the shelf's counter-argument to its own headline. Every flagship shows what
an agent adds; this one shows the protocol charges no **LLM tax** (ADR-0011). Reflexes,
spawn timers, physics and scoring are all local — a round trip would only add latency
to a game whose whole appeal is instant response. The agent's role ended when it
authored the app. **Owned** still applies in full: the high score lives in the player's
own file, hydrated through the same handshake every serious app uses. And **sufficient**
inside the sandbox: pigs, food, clouds and terrain are emoji over CSS gradients, every
oink and splat is synthesized on the fly — no remote asset is ever missed.

The emotional core is the kid. A game a child built, that a child can play, whose best
score belongs to the family's own file — software ownership starting at age eleven.
